Ant ERP API v1

A versioned REST API that lets other systems read from and write to the Ant ERP, documented with OpenAPI.

  • REST API
  • OpenAPI
  • OAuth 2.0
  • Integrations

The problem

Other systems had no safe, documented way to exchange data with the ERP. Every integration would have meant custom work and guesswork about the data.

What it does

  • Versioned as v1, so later changes don't break systems already connected to it.
  • OAuth client credentials: each integration gets its own client UUID and secret, and swaps them for short-lived access tokens.
  • Scoped access: every client is limited to the read and write permissions it needs, such as reading customers or writing invoices.
  • Secrets expire (180 days by default) and can be rotated, and clients can be revoked or deleted from one admin page.
  • Quick connect: an add-on can register itself with a one-time code, with no manual setup.
  • A full OpenAPI specification that integrators can read, and generate client code from.
  • Already in use: FleeV, the garage management add-on I built, connects to the ERP through this API.

My role

At Virtual System Solutions I designed and built API v1, set up its OAuth authentication (client credentials, scopes, secret expiry and rotation), and wrote the OpenAPI documentation. I also built the integration page above, where admins create, scope and manage API clients. The documentation is private to the company, so private details in the screenshot are blurred.
